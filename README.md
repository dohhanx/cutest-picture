# Snow Hug

A chubby fluffy white baby harp seal pup cuddles a tiny grey penguin chick. The chick wears an oversized red pom-pom beanie and kisses the seal's cheek, while snow falls around them.

`main.ts` does not draw. It checks `art/snow-hug.jpg` (a JPEG of at most 1 MiB and 1024 by 1024) and copies those bytes to `/output/entry.png`. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else.
